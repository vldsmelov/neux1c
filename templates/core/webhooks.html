📖 Документация по интеграции

Payload (пример для funding_case.status_changed):

POST /your-endpoint
Content-Type: application/json
X-NEUX-Signature: hmac-sha256-hex
X-NEUX-Event: funding_case.status_changed
User-Agent: NE-UX-Webhook/1.0

{
  "event": "funding_case.status_changed",
  "timestamp": "2026-06-01T12:34:56Z",
  "data": {
    "case_id": 1,
    "code": "FUND-DEMO-1",
    "name": "Закупка стройматериалов",
    "organization": "ООО \"Гладиолус\"",
    "old_status": "active",
    "new_status": "waiting_for_inflow",
    "url": "/funding/cases/1/"
  }
}

Проверка подписи (Python):

import hmac, hashlib
signature = hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
assert signature == request.headers["X-NEUX-Signature"]

Retry-политика: 10 подряд неудачных ответов (не 2xx) → подписка автоматически отключается. Включите вручную после исправления endpoint-а.
