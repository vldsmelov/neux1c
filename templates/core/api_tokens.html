📖 Документация API

Заголовок аутентификации:

Authorization: Token <your-uuid>

Доступные эндпоинты:

  • GET /api/v1/ — корень с описанием API
  • GET /api/v1/funding-cases/?status=active — список кейсов
  • GET /api/v1/funding-cases/<id>/ — детальная карточка с overview
  • GET /api/v1/payment-facts/?from=2026-01-01&to=2026-12-31&organization_id=N — факты
  • GET /api/v1/exchange-rates/?currency=USD — курсы валют

Пример:

curl -H 'Authorization: Token YOUR-UUID' http://server/api/v1/funding-cases/
